### Баги, найденные и исправленные при тестировании на реальной плате (ESP32-C3 + GoPro 11)
Раньше GoPro вообще не подключалась / подключалась, но статус не обновлялся. Причины (все в src/gopro_ble.h):
1. `NimBLEScan::start()` принимает длительность в **секундах**, а не в мс — плата уходила в скан на 4000 секунд вместо 4
2. Полное выключение Wi-Fi (`WiFi.mode(WIFI_OFF)` / `softAPdisconnect(true)`) вешало плату намертво при уже активном BLE — теперь портал просто останавливает веб-сервер/DNS, саму точку доступа не трогает (см. status_portal.h `stop()`)
3. Не было `_pClient->secureConnection()` — без явного шифрования линка GoPro молча не отвечала на запросы статуса
4. Подписка была только на Query Rsp характеристику — GoPro (по своему демо-коду) требует подписку на ВСЕ notify-характеристики сразу после подключения
5. Off-by-one в разборе TLV-ответа статуса (parseQueryPayload) — портил первое поле (BATTERY_BARS)
6. NVS-ключ длиннее лимита 15 символов при сохранении имени привязанной камеры (bonded_cameras.h) — убраны двоеточия из MAC-адреса для ключа

Всё это подтверждено рабочим логом: GoPro находится, подключается, статус (battery/sd/recording) обновляется корректно.

## Что проверено дополнительно
- Режим **AIR** (запись стартует/останавливается по arm/disarm FC) подтверждён рабочим на живом стенде (2026-09-18).
- **Статус SD-карты** (ID 33, GoPro 11 Mini) подтверждён рабочим — корректно отражает реальное состояние карты (2026-09-20).

## Что НЕ проверено / что делать дальше
- Режим **SWITCH** (запись по AUX-каналу) не проверен на живом FC
- Многобайтовые статусы SD-карты (SD_REMAINING, SD_CAPACITY — 8-байтные значения) в тесте пришли нулями — возможно, реальные данные появляются только при вставленной SD-карте с данными, надо перепроверить с картой
- Расшифровка кодов ошибок SD-карты (SD_ERRORS) в текстовые статусы не сделана — выводится сырое число
- DJI/Insta360 — не поддерживаются на ESP32-C3 (см. README, раздел "Тестирование по камерам"), проект остаётся на этом чипе

## Как продолжить на другом компьютере
```
git clone https://github.com/andrewkena/airsqad-cam-linker.git
cd airsqad-cam-linker
git pull   # если уже склонировано раньше
```
Прошивка: `pio run -e esp32-c3-supermini -t upload --upload-port COMx` (порт платы — через `pio device list`).

Этот файл можно удалить, когда информация из него перестанет быть актуальной.
